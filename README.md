# Fatima Saleem — portfolio

A responsive static website in HTML, CSS and JavaScript. No dependencies or build step.

## Preview
Open index.html in a browser, or run `python -m http.server 8000` in this folder and visit http://localhost:8000.

## Deploy to Vercel
1. Extract the ZIP. Create a GitHub repository and upload the contents of this folder (index.html, style.css, script.js, assets).
2. Import the repository in Vercel. Select Other as the framework preset; leave build command blank and use the repository root as output.
3. Deploy. GitHub repository fetching requires network access and is subject to API rate limits. The contact form opens the visitor's email application.
